# Catch Uncle Dags!

A browser-based pixel arcade game built with HTML, CSS and JavaScript.

## Run it

The game can be opened through a local web server. The easiest option in VS Code is the **Live Server** extension.

1. Open this folder in VS Code.
2. Install the "Live Server" extension if you don't have it.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

## Controls

- Arrow Left / A = move left
- Arrow Right / D = move right
- Escape = pause/resume
- Space = start/restart from menus

## Optional audio

Put your own files in `assets/`:

- `music.mp3`
- `catch.wav`
- `miss.wav`

The game still works without them.

## Character artwork

The current version uses hand-drawn pixel shapes as placeholders so the game runs immediately. Later, replace the drawing functions in `game.js` with actual pixel-art sprite images if you want custom Hev Abi / Uncle Dags artwork.
